Project 01 · 2026 · Completed

Compose with the SDGs

Translating UN SDG data into music · Sensing global issues through sound

Data SonificationInteraction Design User ResearchWeb AudioFrontend Dev

SDG data is vast and uneven — traditional charts struggle to create emotional resonance. This project explores whether sonification-driven interaction can make complex global data more approachable, while prompting reflection on what missing data reveals about the world.

Design Process
1
Course Prototype
Built initial sound-mapping prototype in SuperCollider to validate the data→note interaction logic
2
User Research · Usability
Collected feedback via questionnaires and interviews; identified key usability issues
3
Iteration · Tech Migration
Redesigned interaction based on findings; migrated from SuperCollider to HTML/CSS/JS + Tone.js
4
Expansion · Academic Output
Added map interaction, live score visualization, key control; accepted at ICAD 2026
Tech Stack
HTML / CSS / JavaScript
Tone.js · Web Audio API
Mapbox (map interaction)
Figma · Git / GitHub
Interface Preview

Map Interaction
+ Live Score Generation

Click a country to add its SDG data as a note — build a melody while exploring global sustainability gaps.

Project 02 · 2025 · Exhibited

Echo of Action

Gesture-driven installation exploring space resource ethics · KTH & Tekniska Museet

Interaction DesignUnity · MediaPipe Gesture RecognitionUser EvaluationExhibition

Visitors control three virtual planets using body gestures — extracting or conserving resources triggers contrasting visual and auditory outcomes. The installation embodies space ethics and environmental themes, exhibited at Navet Festival with real user evaluation.

Key Contributions
1
Concept & Narrative
Led the creative concept, defined the interaction narrative structure and multimodal experience framework
2
Gesture System Design
Designed and implemented real-time gesture recognition using Unity + MediaPipe, driving planet state changes
3
Museum & Supervisor Collaboration
Negotiated exhibition requirements with Tekniska Museet; regular supervisor discussions to refine direction
4
User Evaluation
Recruited on-site participants; designed and ran pre/post questionnaires and post-exhibition interviews
Tech Stack
Unity · C#
MediaPipe (gesture)
SuperCollider (sound)
Figma (prototype)
Installation View · Tekniska Museet · 10/10/2025
Exhibition Record

Project 03 · 2024 · Group Project

Studyability Map

Helping international students find their ideal university · KTH · DH2321

Information VisualizationVis Design Lead Frontend DevUser Evaluation

Studyability Map helps prospective students navigate the overwhelming process of choosing a university abroad. Filter 621 universities across 67 countries by temperature, cost of living, tuition, rankings, and more — with parallel coordinates, scatterplot, and interactive map syncing in real time.

Key Contributions
1
Visualization Design Lead
Led the visual language — color system, hierarchy, and multi-view sync logic ensuring real-time consistency across all views
2
Frontend Development
Built the interactive system in TypeScript; implemented data loading and processing logic, faithfully reproducing the design intent
3
User Evaluation
Participated in 3 rounds of staged classroom critique; collected peer and supervisor feedback to drive iterative refinement
Tech Stack
TypeScript
D3.js (parallel coords · scatter)
Mapbox (geo visualization)
HTML / CSS · Figma
Interface Preview
Parallel Coords · Scatter
+ Map Sync

Multi-dimensional filters sync instantly to the map and ranked list, enabling cross-country comparison at a glance.

Project 04 · 2024 · Group Project

Commuticate

Non-distracting safety communication system for cyclists · KTH

UI DesignUser Research PrototypingPhysical DesignFigma

Commuticate combines a handlebar-mounted physical device with a mobile app to help cyclists log and share road incidents without breaking their focus. The device uses vibration and buttons to mark hazards; the app provides incident logs, a community map, and discussion threads.

Key Contributions
1
User Research
Conducted Bodystorming as a commuter cyclist; interviewed users and a domain expert to surface core needs and design constraints
2
Physical Prototype
Participated in hardware assembly — soldering, sensor integration, and usability testing to validate the interaction logic
3
Full App UI Design
Independently designed all app screens (login, incident log, community map), establishing a unified visual system
Research Methods
Bodystorming
Literature Review
User Interviews
Physical Prototype · Handlebar + Sensors
