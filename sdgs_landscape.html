Compose with the SDGs

将联合国可持续发展目标数据转化为音乐 · 用声音感知全球议题

Data Sonification Interaction Design User Research Web Audio Frontend Dev

SDG 数据庞大、分布不均，传统图表难以引发情感共鸣。这个项目探索：声音化交互能否让复杂的全球数据变得更具接近感，同时引导用户反思数据缺失背后的社会议题。

设计过程
1
课程原型
基于 SuperCollider 构建声音映射原型，验证"数据→音符"的基础交互逻辑
2
用户研究 · 可用性测试
通过问卷与用户访谈收集反馈，识别核心可用性问题
3
迭代设计 · 技术迁移
根据反馈重构交互；从 SuperCollider 迁移至 HTML/CSS/JS + Tone.js
4
功能扩展 · 学术输出
新增地图交互、实时五线谱可视化与调性控制；成果获 ICAD 2026 接收
技术栈
HTML / CSS / JavaScript
Tone.js · Web Audio API
Mapbox（地图交互）
Figma · Git / GitHub

+ 实时乐谱生成

点击国家地图选取 SDG 数据，音符实时加入五线谱，支持调性与速度调节
