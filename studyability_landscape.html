Project 03 · 2024 · Group Project

Studyability Map

帮助留学生找到理想大学与城市 · KTH · DH2321 Information Visualization

Information Visualization Vis Design Lead Frontend Dev User Evaluation

Studyability Map 帮助有意留学的学生，通过温度、生活成本、学费、学术排名、英语环境等多维指标在全球 621 所大学中自由筛选，在平行坐标、散点图与交互地图的三视图联动中直观探索，让复杂的留学决策变得清晰可见。

核心工作
1
可视化设计主导
主导整体视觉语言，定义配色系统与视觉层级；设计多视图联动逻辑，确保筛选状态跨视图实时一致
2
前端开发
基于 TypeScript 将视觉设计稿转化为可交互系统，实现数据加载与处理逻辑，高度还原设计意图
3
用户评估
参与 3 轮阶段性课堂展示，收集同伴与导师反馈，驱动每轮迭代优化
技术栈
TypeScript
D3.js（平行坐标 · 散点图）
Mapbox（地理可视化）
HTML / CSS · Figma
界面预览
平行坐标 · 散点图
+ 地图联动

多维度筛选实时同步至地图与列表，支持跨国大学横向比较
